MEJORAS REALIZADAS PARA SEMANA 3
1. Se mantiene estructura HTML semántica: header, nav, main, section, article y footer.
2. Se utiliza una hoja de estilos CSS externa correctamente vinculada.
3. Se aplica modelo de cajas mediante padding, margin, border y box-sizing.
4. Se mejora el esquema de colores y tipografía para legibilidad y estética.
5. Se utiliza Flexbox en navegación, tarjetas y pie de página.
6. Se utiliza CSS Grid en catálogo de productos y sección informativa.
7. Se agregan media queries para escritorio, tablet y móvil.
8. Se usan selectores de clase, ID, :hover, :focus-visible y :nth-child.
9. Se dejó preparado el proyecto para realizar la revisión responsiva y guardar capturas en tres resoluciones.
