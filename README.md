# The Storex - Semana 6 (PFY2201)

Proyecto académico de eCommerce desarrollado con Bootstrap 5 y JavaScript.

## Funcionalidades
- Diseño responsivo con Bootstrap 5.
- Barra de navegación con categorías simuladas.
- Productos cargados desde `data/juegos.json` mediante Fetch API.
- Búsqueda procesada con evento `submit`.
- Agregar productos al carrito mediante evento `click`.
- Resumen dinámico del carrito manipulando el DOM.
- Manejo amigable de errores de carga.
- Código organizado en funciones reutilizables y comentadas.

## Ejecución local
Debido al uso de Fetch API, se recomienda ejecutar el proyecto con Live Server en Visual Studio Code o mediante un servidor HTTP local.

## GitHub Pages
Publicar el contenido del proyecto en un repositorio público y habilitar GitHub Pages. La estructura utiliza rutas relativas compatibles con Pages.
